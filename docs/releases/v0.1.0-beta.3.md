The third beta of **GB Cartographer**, a pixel painter and palette companion for [GB Studio](https://www.gbstudio.dev) projects.

> **Beta.** Use it on GB Studio projects you have backed up (a copy, or version control): it writes into the project
> when you save, and keeps a backup of every file it overwrites. Close GB Studio while you work.

### Fixed since beta 2

- **Palettes never revert.** A palette edited in the Palettes window could come back with its old colors a moment
  later: an undone brush stroke dragged the picture's palette list back in time, and the next save wrote it over the
  file. Only a palette you recolored in a picture is written now; every other copy follows the project.
- **Projects with more than 255 palettes.** Each tile's palette was stored in a byte, so palettes past position 255
  painted and saved as the wrong palette. Tiles carry 16 bits now; older drafts and sessions still open.
- **Sprites as GB Studio reads them.** Three shades (Light, Mid, Dark) and the see-through key, as GB Studio 4.3.2's
  own rule; the third green (#306850) shows as Dark and is never written into a sprite file; a Merged pixels view
  finds such pixels.
- **Backups out of the project.** GB Studio's save step reads every `.gbsres`-named path in a project, so backup
  folders inside it broke saving. Backups live in the app's data folder; older ones move out when a project opens.
- A renamed palette's file follows its name; Map Room drags, drops, pans and deletes no longer race or stick.

### New since beta 2

- **Map Room:** backgrounds of any size at their true size; drag pieces (those in the way move over); pan and zoom.
- **Cave or dungeon:** a Floor choice, and the project's own forest, cliff and area stamps for walls and floors.
- **Cliff sheets drawn as a +**, with a 32 px-wall Cliff of its own; `npm run cliff-to-plus` converts a project's.
- **Poster tabs:** each open picture's tab shows the picture, its name and size, and the palettes it wears.
- A Draft layer (new pixels at 50 % over the old picture until you Commit), Shift for straight lines, Alt-turned shapes.

### Install

The builds aren't signed yet. **macOS:** open the `.dmg`, drag the app to Applications; the first time, allow it in
System Settings → Privacy & Security → Open Anyway. **Windows:** run the installer; on SmartScreen click More info →
Run anyway. **Linux:** `chmod +x` the AppImage and run it.
