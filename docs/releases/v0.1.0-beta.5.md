A small update to **GB Cartographer** 0.1.0-beta.4, a pixel painter and palette companion for [GB Studio](https://www.gbstudio.dev) projects.

> **Beta.** Use it on GB Studio projects you have backed up (a copy, or version control): it writes into the project
> when you save, and keeps a backup of every file it overwrites. Close GB Studio while you work.

### Fixed since beta 4

- **Collisions from the Cave and Overworld wizards travel with the project.** They wait in the project's
  `Cartographer/collisions.json` until GB Studio puts the new background in a scene, instead of in one computer's
  browser storage, so they follow the project to another computer. Ones already waiting move in the first time you
  open a background.

### Install

The builds aren't signed yet. **macOS:** open the `.dmg`, drag the app to Applications; the first time, allow it in
System Settings → Privacy & Security → Open Anyway. **Windows:** run the installer; on SmartScreen click More info →
Run anyway. **Linux:** `chmod +x` the AppImage and run it.
