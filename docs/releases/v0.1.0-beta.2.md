The second beta of **GB Cartographer**, a pixel painter and palette companion for [GB Studio](https://www.gbstudio.dev) projects.

> **Beta.** Use it on GB Studio projects you have backed up (a copy, or version control): it writes into the project
> when you save, and keeps a backup of every file it overwrites. Close GB Studio while you work.

### New since beta 1

- **Map Room:** backgrounds of any size at their true size (a 2 × 2 or 3 × 3 picture, or an odd size, takes the
  squares it reaches); drag a piece to move it and pieces in the way move over; Alt-drag nudges by 8 px tiles; drag
  the empty map to pan, Ctrl / ⌘ + wheel or a pinch to zoom; screens fill the window and names show on hover.
- **Asset Catalog:** the home is one four-column mosaic, in the sidebar's order.
- **Sprite sheets:** saving says when an 8 × 16 slice wears two palettes (the game uses the top half's).
- **About:** privacy and terms of use.
- Fixes: right-clicking a palette in the Palettes window no longer crashes; recent projects on Windows ignore case.

### Install

The builds aren't signed yet. **macOS:** open the `.dmg`, drag the app to Applications; the first time, allow it in
System Settings → Privacy & Security → Open Anyway. **Windows:** run the installer; on SmartScreen click More info →
Run anyway. **Linux:** `chmod +x` the AppImage and run it.
