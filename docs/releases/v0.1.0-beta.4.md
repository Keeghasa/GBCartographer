The fourth beta of **GB Cartographer**, a pixel painter and palette companion for [GB Studio](https://www.gbstudio.dev) projects.

> **Beta.** Use it on GB Studio projects you have backed up (a copy, or version control): it writes into the project
> when you save, and keeps a backup of every file it overwrites. Close GB Studio while you work.

### Changed since beta 3

- **Morning (M) replaces Dawn (D)** for time-of-day palettes, because people read D as Day. Your old "… D" palettes
  still show as Morning; the Project check-up lists each one and renames it to M in one click (events find palettes
  by id, so nothing in GB Studio breaks).
- **Sprites have no palettes.** A sprite sheet opens, paints and saves in plain Game Boy greens, exactly what GB Studio
  reads; you colour sprites in GB Studio's own sprite editor, as before.

### New since beta 3

- **Every wizard** remembers its settings per project, keeps named presets, shows live tile and palette-slot counts
  (red over the limit), and has a before / after slider where there's a real before. Palettes a wizard makes can go
  straight into a scene's slots.
- **Two new wizards:** Interior (a room with walls, floor, door, windows and furniture from the catalog's indoor
  tiles) and UI frame (a window frame for GB Studio's ui folder).
- **Picture to background:** your own pictures kept in the project; several pictures at once on one shared palette
  set; turn, straighten and crop first; lock a region to a palette; a choice of dither.
- **GB Snapshot:** your own 3D models kept in the project; free rotate on any axis; a flat (orthographic) lens;
  saved views so all of one model's sprites match; shots named with the time so a second one never collides.
- **Cave or dungeon:** 32 px cells by default, doorways where screens meet, start and end stairs, optional treasure
  and enemy marks, collisions. **Overworld:** paint a rough land and water shape first, biomes (grassland, desert,
  snow, swamp), bridges, collisions.
- **Morning, sunset and night** also makes Underwater (U) and Cave dark (C) versions, and plays the cycle.
- **Palette set:** a colour-blind check. **Tile budget fixer:** a heat map of where the tiles go and Fix all to a
  target count.
- **Project check-up** has more checks and runs quietly when a project opens, with a count on the Wizards button.
- **Reference browser** (desktop app): a small web browser in the project panel for looking things up.

### Fixed since beta 3

- Windows: the "GB Studio is open" warning didn't appear (Windows' process list was slow and timed out).
- A model that refers to files you didn't add (.mtl, .bin, textures) says which ones instead of showing grey.

### Install

The builds aren't signed yet. **macOS:** open the `.dmg`, drag the app to Applications; the first time, allow it in
System Settings → Privacy & Security → Open Anyway. **Windows:** run the installer; on SmartScreen click More info →
Run anyway. **Linux:** `chmod +x` the AppImage and run it.
